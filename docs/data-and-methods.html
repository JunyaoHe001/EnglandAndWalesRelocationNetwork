Data, methods and public-data boundary

This atlas visualises age-specific inter-local-authority migration networks in England and Wales for years ending June 2012–2025, expressed on a common December 2023 Local Authority District geography.

Network construction

Each annual age layer is a directed origin–destination network. A node is a 2023 LAD. An edge points from the origin LAD to the destination LAD and is weighted by the age-group migration estimate.

Age layers

The five layers are Teenagers (15–20), Young adults (20–40), Prime working age (30–50), Older working age (50–65), and Elderly (65+). Upper bounds are exclusive except for 65+. The 20–40 and 30–50 layers overlap at ages 30–39, reproducing the research grouping.

Map encodings

Node size defaults to total migration activity. LAD colour defaults to the bounded migration balance index: (inflow − outflow) / (inflow + outflow). Negative values indicate more outflow and positive values indicate more inflow. Edge width is log-scaled by directed flow.

Published edge subset

The complete processed networks are denser than is practical for a browser map. Each public layer therefore contains the 4,000 strongest directed edges. The interface can display smaller top-ranked subsets and reports the share of complete layer flow retained by the 4,000-edge export.

Public-data boundary

The repository contains aggregate LAD-level metrics and directed-flow estimates only. It excludes raw workbooks, row-level source data, local paths, processing caches and any individual records.
